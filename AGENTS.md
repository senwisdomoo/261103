# Project instructions

This project uses Vanilla JavaScript with Vite. Read and follow these rules before making code changes:

1. Keep HTML, CSS, and JavaScript in separate files.
2. Keep `index.html` at the project root. Put application CSS and JavaScript in `src/`. Keep configuration files such as `vite.config.js` at the project root.
3. Load JavaScript as an ES module. Import application CSS from the JavaScript entry point so Vite includes it in the build.
4. Install external JavaScript libraries with `npm install` and import them in the code. Do not load libraries from a CDN.
5. Inspect existing files and configuration first, then make only the changes needed.

## Netlify deployment

- Build command: `npm run build`
- Publish directory: `dist`
